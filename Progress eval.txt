Assignment Description:
This assessment evaluates students’ initial progress in system development and project
planning. Students are required to clearly identify system requirements, design the overall
system structure using appropriate diagrams, design and develop the database.
In addition, students must create mock-ups or low-fidelity prototypes and begin
implementing their assigned system components.

Evaluation
Criteria The following areas are assessed
• SWOT (Strengths, Weaknesses, Opportunities, Threats) analysis to
determine whether it is realistic and achievable
- Possible risks and how they are handled.
- Design and implementation decisions.
• System Diagrams
- Illustrate the intended structure and behavior of the system. These
may include system architecture diagrams, process or data flow
diagrams, and use-case diagrams.
- Identify key system components, and interactions
- Demonstrate understanding of the system’s logic, functionality, and
how individual components work together to form a cohesive
solution.
• Detailed project requirements and planned functionality based on
priority
- Correct implementation of functionality reflecting the system
requirements and design specifications (35% of product completion)
- Clear evidence of progress and the work completed aligns closely
with each student’s assigned responsibilities.
• Database design
- A well-structured database reflecting the requirements of the system.
- Tables that represent all necessary entities with correct relationships.
- Design decisions justified and aligned with system requirements,
• User Interface
- Well-designed user interface (UI) mock-ups or low-fidelity prototypes
that represent the system’s intended interface.
- UIs are user-friendly, allowing users to navigate and interact with the
system.
- Maintain consistency in layout and design elements.
- Align the UI design with user needs and expectations and overall
system design.
